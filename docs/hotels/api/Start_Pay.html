StartPay

Home > Hotels > StartPay

This API initiates the payment with multiple payment options and initiates booking if the payment is successful.
There are two possible modes Deposit mode and Multi payment mode.
In deposit mode booking is done after debiting the agent and in multi-payment, booking is initiated in another API call, CommitPay, which is initiated automatically initiated, after deducting the amount from bank.

End Point :  {HotelBookingURL}/Payment/StartPay

Method : POST
